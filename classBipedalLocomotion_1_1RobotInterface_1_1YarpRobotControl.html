Detailed Description

YarpRobotControl Yarp implementation of the IRobotControl interface.

Note
The control modes and the references are sent in a best effort way: if the device does not accept them for some joints (e.g. joints in hardware fault), a warning is printed, the other joints are set anyway and false is returned. YarpRobotControl never reads the control modes of the joints, except once in setDriver(): to monitor them use YarpSensorBridge.
Warning
At the current stage only revolute joints are supported.

Set the control mode.

Parameters
controlModesvector containing the control mode for each joint.
Returns
True/False in case of success/failure.
Note
The request is sent for all the joints and the device sets the ones that accept it (e.g. a joint in hardware fault only accepts ForceIdle). If some joints are not set, a warning is printed and false is returned, but the requested modes are stored anyway, so the references of the other joints keep being accepted. The control modes are not read: use YarpSensorBridge to know them, e.g. to leave out the joints in hardware fault.
Warning
At the current stage only revolute joints are supported.
