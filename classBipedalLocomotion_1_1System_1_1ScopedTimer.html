Detailed Description

ScopedTimer closes a TimeProfiler timer when the scope it lives in ends.

The profiler measures the interval between setInitTime() and setEndTime(), so a timer left open by an early return, a break or an exception does not simply lose one sample: it keeps a stale initial time and skews the measurements that follow. Declaring a ScopedTimer instead of pairing the two calls by hand removes the possibility.

{
ScopedTimer timer(profiler, "Inference");
if (!network.advance()) return false; // the timer is closed anyway
}
profiler.profiling();
